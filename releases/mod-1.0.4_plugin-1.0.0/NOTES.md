## 改了什么

**点「小地图设置」就把大地图收起来，点回「大地图设置」立刻恢复。**

上一版（1.0.3）在设置面板里嵌了一块缩略图预览，方案偏重。这一版改回最直接的做法：

- 点「小地图设置」→ 大地图的地图图片、区域、区域名、传送点、怪物/玩家头像、导航路径、
  顶部信息栏、传送点面板、右键选项栏**全部停止绘制**。
- 同时**不再压全屏深色遮罩**，背景直接透出游戏世界（不是黑屏）。
- 这一页里 **HUD 小地图照常显示**：`MinimapManager` 原本遇到 `WorldMapScreen` 就整段跳过，
  现在为这一页开例外，于是小地图按当前「方位 / 大小 / 形状」真实地画在它该在的位置上，
  调一项立刻能看到效果。
- 点「大地图设置」→ 地图立即恢复，遮罩也回来。

### 配套收紧

- 地图收起期间右键不弹选项栏、滚轮不缩放（切回来不会莫名跳变）。
- 切到该页时收起已打开的选项栏与传送点面板。
- `settingsTab` 改用 `SETTINGS_TAB_WORLDMAP` / `SETTINGS_TAB_MINIMAP` 常量。

### 回退说明

1.0.3 的缩略图预览与 `MinimapRenderer.drawMinimap` / `renderPreview` 重构已整体撤销，
`MinimapRenderer` 恢复为 1.0.1 的结构；`MinimapManager` 只保留一处罚定。

## 要不要换 jar

- **客户端必须换**：`startrail-forge-1.0.4.jar` → `versions\时之旅者\mods\`，**需重启游戏**。
- **服务端不用换**：`StarTrail-Plugin-1.0.0.jar` 未变（哈希 `7B27D543…`）。
