## 改了什么

**点「小地图设置」页时把整张大地图收起来，切回「大地图设置」再显示。**

- 设置面板里切到「小地图设置」页 → 大地图的地图图片、区域填充/边框、区域名、多边形区域名、
  传送点图标与名字、怪物头像、玩家头像、导航路径、顶部信息栏（缩放/坐标/操作提示）、
  传送点详情面板、右键选项栏一律不绘制，只留设置面板。
- 切回「大地图设置」页 → 以上全部恢复。
- 齿轮按钮、「返回」、ESC 行为不变。

配套收紧（避免操作到一张看不见的地图）：

- 大地图被藏起来时，**右键不再弹出选项栏**（否则会对着看不见的坐标导航/传送）。
- 大地图被藏起来时，**滚轮不再缩放**（`targetScale` 不会被悄悄改掉，切回来不会跳变）。
- 切到该页时收起已打开的选项栏与传送点面板。
- 页面上加了一行提示「本页已隐藏大地图，切回『大地图设置』即可恢复」；窗口过矮时这一行不画，
  不会压到「返回」按钮。

## 要不要换 jar

- **客户端必须换**：`startrail-forge-1.0.2.jar` → `versions\时之旅者\mods\`，**需重启游戏**。
- **服务端不用换**：`StarTrail-Plugin-1.0.0.jar` 未变（哈希 `7B27D543…`）。
