## 改了什么

**F3 调试屏打开时，小地图自动挪到调试面板下方，不再被挡住。**

### 实现

新增 `DebugScreenProbe`：

* `isDebugScreenOpen(client)` → 读 `client.options.renderDebug`；
* `debugPanelHeight(client)` → 行数 × **9px** + 上下留白（顶部 2 + 底部 4）。

`Gui.debugScreen` 与 `DebugScreenOverlay.getGameInformation()` 都是 **protected**，
没有公开接口，所以用反射取行数；反射失败时退回保守的固定行数，功能不至于整个失效。
（`debugScreen` 声明在父类 `Gui` 上，反射时沿类层次往上查找。）

### 避让策略

**只在会重叠时触发** —— 左下 / 右下方位本来就在屏幕底部，不受影响。

| 情况 | 处理 |
|---|---|
| 屏幕够高 | 小地图整体**下移到面板下方** |
| 屏幕较矮 | **自动缩小**地图，保证能塞进面板下方 |
| 连 48px 都放不下（F3 面板比屏幕还高） | 暂时**隐藏** |

**这只是运行时避让**，不改 `config.startrail.json` 里的方位设置；
关掉 F3 后地图**回到原来的位置和大小**。

## 实机确认清单

1. 换 1.1.25 并重启游戏。
2. 小地图在**右上角**时按 F3 → 小地图应挪到 F3 面板下方，不再被文字盖住。
3. **再按一次 F3 关闭** → 小地图应回到右上角原位、原大小。
4. 若你的窗口较小/GUI 缩放较大，F3 打开时地图会**缩小**（这是有意的取舍，见下文）。
5. 把方位改成**左下角**后按 F3 → 位置不应变化（底部本来就不重叠）。

## 一个取舍

屏高只有 360（GUI 缩放较大或窗口较小）时，F3 面板占掉 276px，下方只剩 79px，
所以地图会**从 128 缩到 74**。

如果你更希望「保持原大小、宁愿略微超出屏幕底部」，把
`MinimapRenderer` 里 F3 避让段的 `availBelow >= 48` 分支改掉即可 —— 告诉我，我来调。
