## 改了什么

**新功能：大地图选中传送点时，图标外围套一个圆圈。**

之前选中状态只有两处体现：图标换成 `textureSelected` 贴图、右侧弹出详情面板。
在地图上「到底选中了哪个点」不够直观，现在补一个明确的圆环标记。

### 实现要点

* 颜色 **`#00D8FF`**（与面板边框、导航路径同色），保持克制的科幻配色。
* 半径 = 图标半径 + **3px** 留白，随图标大小自适应，任何缩放下都能包住图标。
* **逐行计算水平弦宽再填充**，比逐点采样更圆、不会断点。
* **上下边界按行中心对称取整**（以圆心行为基准向外扩 r 行）。

> 第一版用 `ceil(cy + r)` 作为下边界，导致底部多出一行、圆看起来偏下。
> 用字符画核对时发现并修正——修正后包围盒 y[0..24] 高 25、中心行 12、**上下对称**。

## 实机确认清单

1. 换 1.1.16 并重启游戏。
2. 打开大地图，**左键点一个传送点** → 该图标外围应出现**青色圆环**，同时右侧弹出详情面板。
3. **点另一个传送点** → 圆圈应移到新的那个，旧的消失。
4. **点空白处** → 圆圈消失。
5. **缩放地图** → 圆圈应随图标一起变大变小，始终包住图标。
6. 若觉得圈偏大/偏小，调 `WarpOverlay.SELECTED_RING_PAD`（当前 3）。
