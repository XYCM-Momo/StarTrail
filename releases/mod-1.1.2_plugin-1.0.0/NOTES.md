## 改了什么

**1.1.1 没修对：标点仍在屏幕左侧，且向右转视角时标点跟着往右跑。**

- 现象：目标实际在左侧，标点却显示在右侧；向右转身时标点往右移（正确应往左移）。
- 成因：`right` 基向量取反了。
- 修法（三处一起改，缺一不可）：
  1. `right = (-cos yaw, 0, -sin yaw)`，即 `Camera#getLeftVector()` 取反。
  2. `up = right × forward`。**改 `right` 符号会连带翻转 `up`**，上一版只改了一个，所以左右对了上下又反。
  3. 视野外贴边箭头不再单独推 `bearing ± yaw`，改为用与投影**同源**的 `right`/`forward` 求
     `rel = atan2(dir·right, dir·forward)`。此前投影与箭头各写一套三角函数，是左右反复打架的根源。

## 这次的验证方式

前两版都栽在「用自己的公式验证自己的公式」。这一版改用**「转身不变量」**——
一个不依赖任何内部约定、玩家用键盘就能感知的事实：

> 目标固定在世界某处，玩家**向右转**时，目标在屏幕上必须**向左**移。

用这个判据一测就分清了：
- `(cos yaw, 0, sin yaw)` → 向右转时标点**右**移 = 镜像（1.1.1 就是它）
- `(-cos yaw, 0, -sin yaw)` → 向右转时标点**左**移 = 正确
