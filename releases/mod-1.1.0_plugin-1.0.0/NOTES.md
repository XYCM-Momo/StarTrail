## 改了什么

**新增：导航时除了地面红石粒子，屏幕上还会出现「导航标点」。**

`/startrail nav <x> <z>` 原来只有地面粒子引路，地形起伏、抬头看天或进洞穴时容易跟丢方向。
这一版补一个始终可见的屏幕标点：

- **目标在视野内**：目标位置画四角准星 + 中心点，上方显示「导航目标  123 格」。
- **目标在视野外/身后**：标点贴到屏幕边缘，箭头指出方向并显示距离
  （正前在正上方，顺时针沿边缘走）。
- 距离 ≥1000 格压成「1.2k 格」。
- 目标进到 3 格内不再绘制（导航本身在此距离也会自动结束），免得糊在准星上。
- 只在导航所在的世界显示，去下界/末地不会还指着主世界的坐标。
- 配色与大地图/小地图上的导航路径同为青色 `#00D8FF`。

### 配置开关

`config/startrail.json` 新增：

```json
"nav": { "showMarker": true }
```

设为 `false` 则只剩地面粒子。老配置没有该字段时按 `true` 处理。

## 实机确认清单

1. `/startrail nav 0 0`（换成实际坐标）→ 屏幕上应出现目标标点，随转头跟随。
2. 背对目标 → 标点应贴到屏幕边缘，箭头指向目标方向，距离随接近递减。
3. 抬头/低头 → 目标在视野内时准星应落在目标上，不跑偏、不镜像。
4. 走进洞穴或地形遮挡 → 标点仍显示（当前不做遮挡剔除，这是有意为之）。
5. 改 `config/startrail.json` 的 `nav.showMarker` 为 `false` → 标点消失，只剩地面粒子。
