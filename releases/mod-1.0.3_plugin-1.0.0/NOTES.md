## 改了什么

**「小地图设置」页改成能实时看到小地图效果的预览。**

1.0.2 把该页的大地图整张藏掉了，但页面只剩底色，调「方位 / 大小 / 形状」时看不到任何效果。
这一版保持「隐藏大地图」不变（那页不需要看世界地图），但：

- 面板在该页加宽到 560，**左侧新增一块游戏界面缩略图**（按游戏界面真实宽高比），
  右侧仍是原有控件。
- 缩略图里按当前配置**实时画一份小地图**：方形/圆形底、地图图片、区域、多边形区域、
  传送点、怪物与玩家头像、朝向扇区、导航路径、区域名，全部与 HUD 同源。
- 改任何一项设置后立刻重画，不必关掉面板再看。
- 缩略图放不下时（窗口过矮过窄）自动不画，控件退回原来的居中布局。

### 内部重构

- `MinimapRenderer.render()` 的绘制主体抽成 `drawMinimap(...)`，HUD 与预览共用同一份代码。
- 尺寸 / 缩放从字段改为参数，`renderRegionBorders` 同步接收 `zoom`。
- `renderNavPath` 仍读字段，预览时临时对齐并在 `finally` 里还原，不影响 HUD。
- `MinimapManager` 增加 `renderPreview(...)` 转发。

## 要不要换 jar

- **客户端必须换**：`startrail-forge-1.0.3.jar` → `versions\时之旅者\mods\`，**需重启游戏**。
- **服务端不用换**：`StarTrail-Plugin-1.0.0.jar` 未变（哈希 `7B27D543…`）。
