## 改了什么

修复**大地图打开设置面板后，区域名与传送点名浮在面板上方**的问题。

- 现象：大地图左下角齿轮打开设置后，主城区域名（含下方类型行）、主城/竞技场传送点名若落在设置面板范围内，
  不隐藏也不被压在面板下方，而是盖在面板上方，压住设置项文字。
- 成因：面板底色走 `fill()`，名字走 `drawString()`。1.20.1 的 GUI 里文字 glyph 与 fill 属于不同绘制批次，
  **文字批次更晚提交**，所以后画的面板底色盖不住文字。
- 修法：①设置面板整体抬到 `z=400`（与右键选项栏同一套做法）；②区域名、多边形区域名、传送点名
  与设置面板矩形相交时不绘制；图标不动（`fill`/`blit` 本来就会被面板正常盖住）。

## 要不要换 jar

- **客户端必须换**：`startrail-forge-1.0.1.jar` → `versions\时之旅者\mods\`，**需重启游戏**。
- **服务端不用换**：`StarTrail-Plugin-1.0.0.jar` 与 1.0.0 发布时完全一致（哈希 `7B27D543…`）。
