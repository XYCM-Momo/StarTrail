## 改了什么

两个小改动：**导航指令不再重复提示**（服务端）、**视野外标记简化为一个点**（客户端）。

### 1. 重复提示（服务端 1.0.3）

**现象**：OP 给自己执行 `/startrail nav stop <自己>` 时同时收到两条：
服务端回显「已让 Xy_Momo 停止导航」+ 客户端提示「[导航] 服务器已停止你的导航」。

**原因**：成功回显发给 `sender`，客户端提示发给被导航的玩家；同一个人的时候就重复了。

**改法**：成功回显**只写控制台日志**，不再发给玩家；玩家只收到客户端那一条。

| 情况 | 行为 |
|---|---|
| 玩家执行成功 | 只写日志，玩家不再收到服务端回显 |
| 控制台执行成功 | 写日志 + 发给控制台 |
| 用法错误 / 玩家不在线 / 没权限 | **照常回给执行者**（否则不知道哪里输错） |

`nav-sent` / `nav-stop-sent` 两个语言键已无代码引用，保留仅为兼容旧配置，已加注释标注。

### 2. 视野外标记简化（客户端 1.1.9）

演变过程：箭头（依赖朝向角，视角一偏就错位）→ 圆圈 + 中心点（形状仍偏重）→ **现在只留一个小点**。

落点本身就表示方位（贴在屏幕哪一侧），一个点已经足够。
删掉了已无调用者的 `drawRing`，不再留死代码。

## 要不要换 jar

**两端都要换**：

* 客户端 `startrail-forge-1.1.9.jar` → `versions\时之旅者\mods\`（需重启游戏）
* 服务端 `StarTrail-Plugin-1.0.3.jar` → `时旅服务端\plugins\`（**需先关服**）
