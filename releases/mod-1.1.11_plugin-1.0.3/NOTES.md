## 改了什么

五项界面调整。

### 1. 大地图区域名去掉黑色阴影底

名字直接压在贴图上，不再有半透明黑底衬。画面更干净。
命中判定仍按原来的 3px 内边距计算，没有因此产生错位。

### 2. 传送点不再显示名称

大小地图上都只显示图标。名字改由「选中后的详情面板」承担，地图上不再互相压字。

> `WarpOverlay.render` 的 `textRenderer` / `labelAbove` / `panelX0..panelY1` / `hideRect`
> 因此不再参与绘制，方法上已加注释说明（签名保留，避免大范围改重载）。

### 3. 传送点层级提到玩家头像之上

大小地图都改。以前站在传送点点位上时，图标会被自己的头像盖住。

> ⚠️ 这**覆盖了 1.1.10 的「自己头像最上层」**——按使用者的取舍，传送点优先。

### 4. 传送点详情面板改为动态高度

面板高度按「标题 + 描述行数 + 坐标 + 按钮」的实际内容计算，不再固定 150。

| 描述行数 | 面板高度 |
|---|---|
| 0 行 | **85 px**（旧实现固定 150，省下 65px） |
| 1 行 | 98 px |
| 2 行 | 108 px |
| 3 行 | 118 px |
| 4 行 | 128 px |
| 6 行 | 148 px |

宽度也改为按内容自适应（200~280 之间）。

### 5. 小地图坐标加上 Y 轴并改为白色

`X: -141.8  Y: 72.0  Z: 187.8`，颜色由黄色改为白色。

## 要不要换 jar

**只需客户端**：`startrail-forge-1.1.11.jar` → `versions\时之旅者\mods\`，**需重启游戏**。
服务端 `StarTrail-Plugin-1.0.3.jar` 不变。

## 实机确认清单

1. 换 1.1.11 并重启游戏。
2. 大地图：区域名**没有**黑色底衬，直接显示在贴图上。
3. 大地图/小地图：传送点**只有图标、没有名字**。

5. 大地图点一个传送点：面板紧凑贴合内容，描述短时不再有一大块空白。
6. 小地图下方坐标显示 **X / Y / Z 三项**，且是白色。
