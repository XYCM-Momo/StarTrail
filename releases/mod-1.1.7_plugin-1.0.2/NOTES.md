## 改了什么

修两个问题：**视角转向不平滑**、**大地图右键「导航至此」后看不到转向**。

### 1. 不平滑（根因是更新频率，不是曲线）

1.1.6 把转向放在 `NavigationManager.tick()` 里推进，那是**游戏刻 20Hz**。
转 90° 时每刻跳 4.5°，实测**最大跳变 20.68°**，肉眼就是「一格一格」。
只调时长或缓动曲线都治不了——**必须提高更新频率**。

* 改为由 `RenderGuiEvent.Post` **逐帧**推进（60~144Hz）。
* 插值曲线由 ease-out 换成 **smoothstep（ease-in-out）**：首尾导数为 0，起步收尾不突兀。

量化对比（转 90°、600ms，相邻更新间的最大角度跳变）：

| 实现 | 最大跳变 |
|---|---|
| 20Hz + ease-out（1.1.6） | **20.68°** |
| 60fps + smoothstep | **3.75°** |
| 144fps + smoothstep | **1.56°** |

改善 5~13 倍。

### 2. 右键「导航至此」不关地图

原来只关右键菜单，大地图仍盖在屏幕上，而视角转向发生在屏幕后面，自然看不到。
现在点「导航至此」会**同时关闭大地图**（与「传送到此处」的行为一致）。

## 要不要换 jar

服务端 `StarTrail-Plugin-1.0.2.jar` 不变。

## 实机确认清单

1. 客户端换 1.1.7 并重启游戏。
2. 面朝反方向执行 `/startrail nav <你> <x> <y> <z> 测试点` → 视角应**明显更连续**，不再一格一格。
3. 打开大地图 → 右键某处 → 点「导航至此」 → **大地图应立刻关闭**，
   并且能看到视角平滑转向该点。
4. 若仍觉得快/慢，可调 `NavViewTurner` 的 `BASE_MS_PER_90_DEG`（默认 600）与 `MAX_MS`（默认 1600）。
