## 改了什么

**修复：大地图滚轮缩放是「跳变」的，没有平滑过渡。**

### 根因

渲染循环里**本来就有**缓动（`scale` 每帧向 `targetScale` 靠近），
但滚轮处理里有一句 `this.scale = this.targetScale;`，**把缓动直接抵消掉了**——
所以每次滚轮都是瞬间跳完，看不到任何过渡。

另外 `worldmap.smoothZoom` 这个配置项虽然早就存在，**代码里从来没有读过它**，是个死配置。

### 改法

1. 滚轮只更新 `targetScale`，由渲染循环逐帧过渡（去掉那句强制赋值）。
2. 平滑系数取 **0.35**：单次滚轮幅度 20%，首帧只走 **7%**，约 **11 帧 / 0.18 秒**到位。
3. **鼠标锚点**：过渡期间每帧围绕「滚轮时鼠标所指的世界坐标」重定位相机，
   保证鼠标指着的地方不漂移；缩放到位后清空锚点。
4. **接上 `smoothZoom` 配置**：设为 `false` 时恢复旧版瞬切行为。
5. 两处防冲突：开始**拖动地图**时清空锚点（否则相机会被锚点拽回、拖不动）；
   **跟随玩家**时不设锚点（等价于以玩家为中心缩放）。

## 实机确认清单

1. 换 1.1.15 并重启游戏。
2. 打开大地图，**快速滚动滚轮** → 缩放应有平滑过渡，不再一跳一跳。
3. **连续滚动多格** → 过渡应自然衔接，不卡顿。
4. 缩放过程中**注意鼠标所指的位置** → 该位置应保持不动（锚点生效）。
5. 缩放后**拖动地图** → 应能正常拖动（锚点已清理）。
6. 若觉得还不够顺或有过冲感，可调 `WorldMapScreen.ZOOM_SMOOTHING`
   （0.35 当前值；越小越柔但越慢，越大越快但跳变感回升）。
