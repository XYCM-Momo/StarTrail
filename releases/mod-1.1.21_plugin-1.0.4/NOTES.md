## 改了什么

### 1. 地区名一直不出现（1.1.20 的 bug）—— 查错了存储

线上 `regions.yml` 里的区域 **全部是 `shape: polygon`**（放在 `polygons:` 段下），
而 1.1.20 的 `currentRegionName` 只查了**矩形区域**存储 `regionDataStore`，
所以永远查不到东西，地区名一次都不会显示。

**修法**：两类都查——

* **多边形优先**（功能分区如「后勤部」比整片矩形大陆更具体）
* **矩形兜底**

`PolygonRegion` 没有现成的包含判断，用**射线法**自行实现。

### 2. 大地图跟随昼夜明暗

把 `computeBrightness` 从 private 改为 **public**，
大地图绘制地图图片时用它算顶点颜色（原来硬编码 `255,255,255,255` 全亮）。

现在两个视图**共用同一个亮度函数**：

| 时刻 | 亮度 |
|---|---|
| 正午 12:00 | 1.000 |
| 傍晚 18:00 | 0.700 |
| 午夜 00:00 | **0.400** |

不会再出现「夜里小地图变暗、大地图还全亮」的割裂感。

## 实机确认清单

1. 换 1.1.21 并重启游戏。
2. 走进**主城**（八边形区域）→ 小地图坐标下方应出现 `主城`。
3. 走进**后勤部**（矩形区域）→ 应显示 `后勤部`（多边形优先，若同时命中主城则显示后勤部）。
4. 走到区域外 → 地区名那一行消失，不留空白。
5. 打开大地图 → 地图贴图应和小地图**同步变暗**；夜里（或 `/time set midnight`）两边都明显变暗。
6. `/time set noon` → 两边都应恢复最亮。

## 待确认

线上 `regions.yml` 目前只定义了两个区域（主城、后勤部）。
其它地方走动时地区名不显示是**正常的**（不在任何区域内），不是 bug。
若希望更多地方有名字，需要服务端补区域配置。
