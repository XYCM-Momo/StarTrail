## 改了什么

**修复：小地图上自己的头像不是最上层，会被其他玩家头像或导航路线挡住。**

### 原因

小地图的绘制顺序原来是：

```
自己的头像 → 其他玩家头像 → 导航路径
```

后画的会覆盖先画的。**只要有别的玩家或导航路线经过小地图中心，自己的头像就被压在下面。**

### 改法

调整为：

```
朝向扇形 → 其他玩家头像 → 导航路径 → 自己的头像
```

把自己那一份放到**最后画**，保证永远在最上层。
朝向扇形仍放在自己头像之下，否则扇形会反过来盖住头像。

## 要不要换 jar

**只需客户端**：`startrail-forge-1.1.10.jar` → `versions\时之旅者\mods\`，**需重启游戏**。
服务端 `StarTrail-Plugin-1.0.3.jar` 不变。
