# 星轨 StarTrail 点位编辑器（本地网页版）

在浏览器里可视化编辑导航点位，免去游戏内 `/startrail waypoint add` 一条条敲的麻烦。

## 使用

1. **推荐：双击 `启动编辑器.cmd`** —— 会启动一个本地小服务器并用
   `http://127.0.0.1:3081` 打开编辑器。
   - 用 http:// 打开后，浏览器把文件访问权限、上次目录记忆当作**真实网站来源**持久保存，
     重启浏览器也不会丢（这是 file:// 方式做不到的）。
   - 首次在 http:// 打开时，需要重新导入一次图片、选择一次点位文件（浏览器数据按来源隔离，
     之后就一直记住）。
   - 关闭弹出的服务器窗口即停止服务器。
2. 也可以直接双击 `StarTrail点位编辑器.html` 在浏览器中打开（纯本地、无需服务器）；
   但 file:// 页面下「选择点位图文件」的**目录记忆**和文件访问权限在浏览器重启后会失效
   （浏览器对 file:// 来源不持久保存权限，选择框会回到默认目录）。
2. **导入图片**：点顶部「📥 导入图片」或直接把文件拖进地图区域，支持 PNG/JPG/WebP 以及
   **加密后的 `.mmap` / `.startrail` 文件**（自动用与 mod 相同的算法解密还原，无需手动处理）。
3. **填边界值**：右侧「地图设置」里填好地图 ID、图片文件名、所属世界，以及四个边界值
   `minX / minZ / maxX / maxZ`：
   - 图片左上角（西北角）对应 `(minX, minZ)`
   - 图片右下角（东南角）对应 `(maxX, maxZ)`
   - 图片上边 = 北方（Z 小），左边 = 西方（X 小）
4. **添加点位**：点「➕ 添加点位模式」开启后，在地图上点击空白处即按像素位置换算成世界坐标
   生成点位（X/Z 自动计算，Y 用默认高度）。再点一次按钮或按 `A` 可关闭添加模式。
   **连续串点**：先点一下已有点位（选中），再点空白处新建，两个点位自动双向连通。
5. **编辑点位**：
   - 点击地图上的标记或列表项选中点位，在「选中点位」里改 ID / X / Y / Z，**改动实时生效**（不用点按钮）；
   - 勾选「连通点位」复选框即建立双向连通（与游戏 `/startrail waypoint link` 一致）；
   - 地图上直接拖动标记可移动点位（X/Z 自动换算）。
6. **导出**：
   - 「⬇ 导出点位 JSON」→ 生成 `<地图ID>.json`（格式与客户端/服务端完全一致）；
   - 「⬇ 导出 images.yml 片段」→ 生成图片绑定片段，贴进服务端 `images.yml`。

## 实时编辑已有的点位文件

1. 点顶部「📂 **选择点位图文件**」选一个 `<地图ID>.json`（Chrome / Edge 下弹出系统文件选择框）。
2. 载入后右上角出现「📄 **已绑定: xxx.json（实时写回）**」。
3. 之后**所有修改**（新增/删除/拖动点位、改坐标、改连通、改边界值等）都会在停顿约 0.6 秒后
   **自动写回这个文件**，不用再手动导出。
4. 写回失败（文件被移动/占用/权限失效）会自动解除绑定并提示，重新选择一次即可。

**记忆上次文件**：选过文件后，编辑器会把它的句柄存进浏览器 IndexedDB。下次打开页面时会
**自动恢复**——权限仍有效就直接载入并绑定（无需再选）；浏览器要求重新授权时顶部会出现
「🔁 **重开上次文件**」按钮，点一下即可。同时**文件所在的目录也会被记住**：「📂 选择点位图
文件」下次弹系统选择框时直接打开上次的目录，不用再从默认文档目录一路翻过去。

> 实时写回依赖浏览器 File System Access API（**Chrome / Edge** 支持，双击打开 `.html` 也可用）。
> 用 Firefox / Safari 打开时只能一次性读取，修改后需手动「⬇ 导出点位 JSON」保存。

## 文件放到哪

| 文件 | 服务端 | 客户端 |
| --- | --- | --- |
| `<地图ID>.json` | `plugins/StarTrail/waypoints/` | `.minecraft/startrail/waypoints/` |
| images.yml 片段 | `plugins/StarTrail/images.yml`（然后 `/startrail reload`） | — |

## 说明

- 坐标支持小数（服务端/客户端都接受 double，旧整数也兼容）。
- 自动生成的点位 ID 从 `wp0` 开始；文件里已有带数字的 ID 时，取**最大数字 +1**
  （如已有 `wp5`/`wp12`，下一个自动是 `wp13`；纯字母 ID 如 `a`/`b` 不影响，仍从 `wp0` 起）。
- 数据自动保存到浏览器 localStorage，刷新不丢失；图片过大时刷新后需重新导入图片。
- 「预览 / 粘贴导入」里可以把已有的点位 JSON 或 images.yml 片段贴进去载入继续编辑。
- 宽高比不一致时界面会提示：图片像素宽高比应与边界方块宽高比一致，否则地图会拉伸。

## 像素锐化 & 精确标点（0.5 格吸附）

- **新建点位自动连通**（默认开）：先点一下已有点位（选中），再点空白处新建，两个点位自动
  **双向连通**，可连续"点一个、再点空白"快速串路径；不需要时在「地图设置」里关掉。
- **实时连接线预览**：选中点位后，图上会有一条**黄色虚线**从选中点实时连到鼠标位置
  （开启吸附时指向吸附后的落点），一眼就能看出下一个点位会连到哪。
- **方向键直线创建**：按住 **Shift** + 方向键 / **WASD**，从当前选中点位朝该方向按「步长」
  距离创建点位并自动连通；连续按同方向键可直线延伸（上=北/下=南/左=西/右=东）。
  步长在「地图设置」里改，默认 10 格。
- **连线模式**（<kbd>L</kbd>，与添加/多选互斥）：地图上**先点一个点位再点另一个**即建立双向连通
  （再点一次断开），连完自动以新点位为起点可**连续链式连点**——点位再多也不用翻列表。
  起点带橙色虚线环，黄色虚线实时跟随鼠标提示目标。侧边栏的「连通点位」改为**已连通的 chips
  （✕ 断开）+ 按 ID 筛选勾选**，作为精确管理工具保留。
- **多选模式**（<kbd>M</kbd>，与添加/连线互斥）：点击点位切换选中，**拖拽空白处框选**批量选中，
  选中点带白色虚线环；列表上方出现「🗑 删除选中(N)」一键批量删除（同时清理所有相关连通线）；
  点空白或按 <kbd>Esc</kbd> 清除多选。**关闭多选模式即清空选中**；关闭添加模式后连接线和
  绿色吸附预览也会立即消失，不会残留。
- **添加模式关闭即清预览**：黄色的"下一连接点"虚线和绿色的吸附十字线只在添加模式开启时显示，
  切换关闭时立刻重绘清除，不会卡在画布上。
- **表单实时自动应用**：选中点位后直接改 ID / X / Y / Z 即时生效并自动保存；ID 重复或为空时
  红框提示、暂不应用。给 X/Z 输数值后点「🎯 吸附 X/Z 到网格」可归到网格。
- **🔍 像素锐化**（默认开）：放大时用最近邻采样，不插值，像素保持锐利（地图是方块图时不会糊）。
  如果用的是照片类底图想要柔和缩放，点一下按钮关闭即可。
- **标点吸附**（默认开，网格 0.5）：添加/拖动点位时，X/Z 自动吸附到 **0.5 格**（对应 MC 0.5 方块；
  1 像素 = 1 方块的图上就是 0.5 像素间隔）。网格大小可改（如 0.25 / 1）。
- **网格可视化**：放大到足够大时，图上会叠加吸附网格线——亮线是整数方块、暗线是 0.5 偏移，
  一眼就能看出可标的位置。
- **吸附预览**：开启「添加点位模式」后，鼠标会显示一个绿色虚线圆环 + 十字线，精确指示
  点击后点位会落在哪个吸附格上；状态栏同时显示吸附后的世界坐标。
- 手动输入的 X/Z 不会强制吸附；选中点位后点「🎯 吸附 X/Z 到网格」可以一键把输入值归到网格。

## 加密 .mmap / .startrail 文件

与 mod 端 `ImageCrypto` 完全兼容：

- 文件布局：`MMAP` 魔数 + 版本(1) + 文件名长度(2,大端) + 原始文件名 + IV(16) + AES/CBC/PKCS5 密文；
- 密钥：`SHA-256("MMmap-Xaero-Static-Image-2026")` 的前 16 字节（AES-128）；
- 解密在浏览器本地完成（Web Crypto），文件不会上传到任何地方；
- 导入 `.mmap` 后，`fileName` 会自动填成文件头里的**原始文件名**（如 `overworld.png`），
  与游戏 `resolveImageFile` 的约定一致——客户端会去找同名的 `.mmap`；
- 非 `.mmap`（无魔数）的文件按明文图片直接读取，兼容未加密的 PNG/JPG。

> 注：密钥是 mod 源码里写死的静态密钥，这套"加密"本质是防随手拷贝的混淆，不是强加密，
> 编辑器内置同一密钥仅为与游戏互通。

## 开发/回归测试

```powershell
node _test_harness.mjs "StarTrail点位编辑器.html"
```
