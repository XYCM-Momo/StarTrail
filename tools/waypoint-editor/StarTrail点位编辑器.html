地图设置（边界值）

开启后：先点一下已有点位（选中）→ 再点空白处新建，两个点位会自动双向连通（可连续串点）。
Shift + 方向键 / WASD：从选中点位朝该方向按「步长」距离创建点位并自动连通； 连续按同方向键可直线延伸（上=北/下=南/左=西/右=东）。
左上角（西北）= (minX, minZ)，右下角（东南）= (maxX, maxZ)；图片上边 = 北方（Z 小）、左边 = 西方（X 小）。
像素 → 世界：X = minX + 像素x/图宽 × (maxX−minX)，Z 同理。

点位列表（0）

还没有点位。打开「添加点位模式」后在地图上点击即可添加。
多选模式（M）：点击点位切换选中，拖拽空白处框选；Esc 清除多选。

选中点位

点击地图上的点位或列表项进行编辑。
点位多时用「🔗 连线模式」（L）：地图上先点一个点位，再点另一个即互连，再点一次断开。
修改 ID / X / Y / Z 会实时自动应用（不需要点按钮）。在地图上直接拖动该点位也能移动（自动换算 X/Z 并吸附）。

导出

点位 JSON 放到 plugins/StarTrail/waypoints/<地图ID>.json（客户端同步到 .minecraft/startrail/waypoints/）；images.yml 片段贴进服务端 plugins/StarTrail/images.yml 并执行 /startrail reload。
预览 / 粘贴导入（JSON 或 images.yml 片段）
使用说明：导入图片或加密 .mmap（可拖拽）→ 填好边界值 → 开启「添加点位模式」在地图上点击添加 → 拖动/表单修改 → 导出。数据自动保存到浏览器 localStorage，刷新不丢失（图片需重新导入）。.mmap 解密在本地完成，格式与 WaypointManager.WaypointFileData（服务端）及 WaypointStore（客户端）完全一致。
